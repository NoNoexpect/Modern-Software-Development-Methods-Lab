# 概率论与数理统计 · 复习要点

## 一、随机变量与分布

随机变量是把样本空间映射到实数的函数。离散型随机变量用分布律
P(X = x_k) = p_k 描述，连续型随机变量用概率密度函数 f(x) 描述，
满足 f(x) >= 0 且在全实轴上的积分为 1。

## 二、数学期望与方差

数学期望刻画随机变量的平均水平：
E(X) = ∫ x·f(x) dx（连续型），E(X) = Σ x_k·p_k（离散型）。

方差刻画取值的离散程度：D(X) = E(X²) − [E(X)]²。

性质：E(aX + b) = a·E(X) + b；D(aX + b) = a²·D(X)。

## 三、大数定律与中心极限定理

大数定律说明：样本量足够大时，样本均值依概率收敛于总体期望。

中心极限定理说明：独立同分布随机变量之和经标准化后，分布趋近标准正态分布。
这是为什么许多统计方法默认假设数据近似正态分布的理论依据。

## 四、常见分布备忘

| 分布 | 期望 | 方差 |
| --- | --- | --- |
| 二项分布 B(n, p) | np | np(1 − p) |
| 泊松分布 P(λ) | λ | λ |
| 均匀分布 U(a, b) | (a + b) / 2 | (b − a)² / 12 |
| 正态分布 N(μ, σ²) | μ | σ² |
